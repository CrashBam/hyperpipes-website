# Screenshots

Drop game screenshots in this folder, then list them in the `SHOTS` array at the
bottom of `index.html`.

In-game: **H** hides the HUD, **F2** (or **R3** on a pad) takes the shot. Captures
land in `Pictures/HyperPipes`.

Good ones to grab:
- a craft up on the crown of the pipe with the track curving away
- a pass happening around the side of the tube
- the garage / upgrade screen
- a championship standings or trophy screen
- one shot per environment theme

Landscape 16:9 crops best in the gallery.
